# EOL 图卡工作台

这是一个基于 C#、WinForms、.NET 8 和 OpenCvSharp4 的图卡生成工具。图卡生成、预览、批量处理、视频编码和 LightTools 文本输出均由 C# 完成，不需要 MATLAB，也不会调用 `Lt_Source_Creator.exe`。

程序使用统一工作台组织所有功能。窗体、按钮、文本框、数值框、下拉框和自定义控件均在对应的 `.Designer.cs` 中定义，可以继续使用 Visual Studio WinForms 设计器调整；业务 `.cs` 不会在运行时临时创建这些界面控件。

## 统一工作台

左侧导航直接提供七个页面：

1. 基础图卡
2. 3D显示器图卡
3. 串扰像素排列
4. 非整数连续融合
5. 离散光源
6. 图片转 LightTools
7. 图片转视频

切换页面时会保留已打开的页面实例和当前输入。关闭工作台时，各页面会保存设置；后台仍在导出或编码时，程序会阻止误关闭。

## 基础图卡

- 可生成外框、九点图、畸变点阵、上下校正十字、白色矩形、全黑、全白、全红、全绿、全蓝，以及“导入图片并添加白框”。
- 批量导出包含前十种基础图卡；导入图片由当前图卡保存功能单独输出。
- 全黑、全白、全红、全绿和全蓝图的每个 RGB 通道严格只写入 `0` 或 `255`。
- “白框叠加层”可以应用于任意生成图或导入图片，四边距、线宽均可调。
- 可导入 PNG、JPEG、BMP、TIFF、WebP 作为底图，并使用最近邻方式适配目标画布。

### 统一的四边距定义

图案区域统一使用“图案最外缘到画布左、上、右、下边缘的距离”定义：

```text
图案宽度 = 画布宽度 - 左边距 - 右边距
图案高度 = 画布高度 - 上边距 - 下边距
```

- `0` 表示图案外缘贴住对应画布边缘。
- 负值表示图案越过对应画布边缘，导出时只保留画布内的部分。
- 页面会实时显示由四边距计算出的图案宽度和高度。
- “保持尺寸居中”会在不改变当前宽高的情况下重新分配两侧边距。

九点图和畸变点阵同时保留两种定义方式，并在界面中双向同步：

- 外缘方式：按最外侧圆点的实际像素外缘计算四边距和图案宽高。
- 圆心方式：按左上第一个圆点的圆心坐标，以及首末圆心的 X/Y 跨度计算。

圆点半径、行数和列数均可调整。单个圆的像素包围盒直径为 `2 × 半径 + 1`，因此点阵外缘宽度为 `圆心 X 跨度 + 2 × 半径 + 1`，高度同理；半径为 `0` 时生成单像素点。当列数或行数为 `1` 时，对应方向的圆心跨度会自动归零，外缘尺寸等于一个圆的实际像素直径。

## 串扰像素排列

- 周期像素数可在 `1–1024` 之间调整，默认采用最初版的 `8` 像素周期；可选择 `RGB`、`RBG`、`GRB`、`GBR`、`BRG`、`BGR` 六种排列。
- 周期变化时会按当前 RGB 排列确定性重建：小于 `8` 时截取预设前段，大于 `8` 时超出的新增位置默认全灭；因此 `8→4→8` 会恢复完整的 8 像素预设。周期通道严格只写入 `0` 或 `255`。
- 横向规则固定为最初版的 `-3`；界面不再提供横向步进或逐位置 R/G/B 表格，但保留周期输入框。
- 倾斜角 `theta` 与非整数连续融合使用相同单位和语义，每行连续位移为 `3 × tan(theta)`，落入周期单元时向下取整，因此可生成非整数斜率的阶梯式像素排列。
- 倾斜角输入严格限制在 `-89°～89°`。
- 当前相位范围会随周期像素数实时变为 `1–周期像素数`；可保存当前相位，也可批量导出当前周期的全部相位。
- 旧配置中的逐位置通道或横向步进会归一为通道差异最小的六种排列，同时保留原周期像素数和倾斜角；`v1.0.260816` 标签仍完整保留删除前版本。
- 默认倾斜角为 `18.435°`；其每行位移会吸附为精确的 `1`，所以相位 `1–8` 与最初版 `v - 3u + phase - 1` 公式逐像素一致。旧配置只有整数纵向步进时，会用 `atan(纵向步进 / 3)` 自动换算为角度；换算结果若超出产品范围，会裁剪到 `-89°` 或 `89°`。
- 画布、图案外缘四边距、白框叠加层、图片格式和质量均可调整。
- “恢复最初版默认参数”会恢复 `1920 × 1080` 画布、外缘四边距左 `71` / 上 `226` / 右 `72` / 下 `227`（实时区域 `1777 × 627`）、相位 1、RGB 固定 8 像素周期、`18.435°`、关闭白框、PNG 和质量 95；上次导出目录不会被清除。

## 3D显示器图卡

“3D显示器图卡”页面可调整画布分辨率，并分别用外缘四边距定义左、右矩形区域；两个区域都会实时显示宽度和高度。默认画布为 `3200 × 2000`，对应：

| 文件名 | 默认布局 |
| --- | --- |
| `1.B_W` | 白底、左侧黑色矩形 |
| `2.W_B` | 白底、右侧黑色矩形 |
| `3.B` | 白底、左右两个黑色矩形 |

默认四周白边为 `50 px`，左右区域各 `1500 × 1900`，中间白缝为 `100 px`。可保存当前图卡或批量导出三张。为保证 RGB 通道严格只有 `0/255`，这三张图只允许使用 PNG、BMP 或 TIFF 导出。

## 非整数连续融合、离散光源与 LightTools

三个功能通过工作台左侧导航直接进入，并共用一个可在 Designer 中编辑的窗体。它们的处理流程不同，并非重复功能；嵌入工作台时会隐藏窗体内部重复的页签导航，独立打开该窗体时仍保留三个页签。

### 非整数连续融合

- 复现 MATLAB 脚本的连续覆盖率融合：有效周期 `T = spixtol × m`，每行位移为 `3 × tan(theta)`，`picnum` 按非整数超周期循环。
- 支持全白/全黑、固定 1 子像素、可调点亮比例 Duty、红/蓝、自定义左右图片五种图源。
- Duty 表示左眼半周期内部的点亮比例；默认 `0.25` 对应整个周期宽度的 `12.5%`。
- 可交换左右图源；自定义图源尺寸必须一致并与画布相同，不会静默拉伸或裁剪。
- 文件夹批量模式识别同目录下成对的 `<名称>_L`、`<名称>_R` PNG/TIFF。
- 正常模式保持 RGB 颜色；“兼容旧 MATLAB（交换 R/B）”可复现旧脚本文件夹分支的通道行为。
- 可同时保存实际参与融合的左右 TIFF 图源，并输出 LightTools MESH TXT。

连续融合页中的 `pixL` 是横向子像素宽度（毫米），`pixH` 是纵向像素高度（毫米）；它们只用于 MESH 物理范围，不改变融合几何。

### 离散光源

- 纯 C# 复现 `Lt_Source_Creator` 的分辨率、倾角、子像素周期、点亮颗数、组号、分区宽度、策略角、平移量和方向参数。
- 支持白黑、黑白、红蓝及两张自定义图源。
- `组 = -1` 时生成 `0` 到 `周期-1` 的全部组；默认命名格式与原工具一致，例如 `5.00_8_4_0WB.bmp`。
- 可导出单个 LightTools 光源 TXT，或拆分为 `_R.txt`、`_G.txt`、`_B.txt`。
- 写入 TXT 时先完成同目录临时文件再原子替换。切换单文件/三文件模式不会自动删除另一模式的旧文件，建议使用空输出目录或在确认后自行整理。

离散光源页使用完整像素的 X/Y 尺寸（微米）。

### 图片转 LightTools

- 读取 JPEG、BMP、PNG 或 TIFF，并按 RGB 子像素展开为 MESH。
- 可输出一个光源文件，或分别输出 R/G/B 三个光源文件。
- 图片转换页使用完整像素的 X/Y 尺寸（微米）。

## 图片转视频

- 可一次添加多张图片，同一图片也可重复加入列表。
- 可删除、清空、上移或下移列表项，以控制视频中的图片顺序。
- 每张图片可分别设置静止播放时间，新加入图片默认为 `10 s`。
- 输出宽度、高度和帧率可调；源图片会保持宽高比缩放并居中放入黑色画布。
- 默认输出 `MP4 / MPEG-4（mp4v，有损）`，另提供 `MKV / FFV1（无损）` 和 `AVI / HuffYUV（无损）`。
- 三种编码在当前 OpenCV Windows 运行时中均要求偶数宽高；奇数尺寸会在右侧或底部补一列或一行黑色像素，页面会实时显示实际编码尺寸。
- 各段帧数按“累计时间 × 帧率”的终点舍入计算，避免每张图片独立取整造成长视频时长漂移；任何大于 `0` 的极短片段至少保留 `1` 帧。
- 编码先写入同目录临时文件，完成回读验证后才替换目标文件；取消或失败不会破坏已有视频。

MP4 编码有损，不能保证回读后的像素仍严格为 `0/255`。FFV1 和 HuffYUV 在图片不缩放时可保持解码后的像素值，但文件通常明显更大。

## 预览与图片输出

- 鼠标滚轮以指针位置为锚点缩放，鼠标左键拖动画布；画布外区域使用界面背景色。
- 可显示图片中心十字虚线和鼠标所在的零基像素坐标，两项可分别关闭。
- 预览辅助线和坐标只绘制在界面层，不会写入导出的图片。
- 所有数值框都禁止用鼠标滚轮改变数值，避免滚动参数页时误改参数。
- 图片支持 PNG、JPEG/JPG、BMP、TIFF、WebP；JPEG/WebP 可设置质量。
- 要求通道严格为 `0/255` 的纯色图、串扰像素排列图和 3D 显示器图卡，只允许使用 PNG、BMP 或 TIFF 无损导出。
- 单方向最大 `16384 px`；多数生成入口同时限制画布总像素不超过 4000 万，以避免内存耗尽。

## Windows 投图

工作台标题栏右侧提供全局投图工具，投图方式与参考项目一致：将当前原始预览图转换为 24 位 BMP，并通过 Windows 桌面壁纸接口投出。

- “投图当前预览”只投一次；“实时投图”开启后，当前功能页每次生成新预览都会自动替换壁纸，关闭开关后停止更新。
- “停止投图”会停止后台更新；勾选“停止时恢复原壁纸”时，还会恢复本次首次投图前保存的壁纸路径。
- 可选择保持当前显示模式，或显式应用“仅电脑屏幕、复制屏幕、仅第二屏幕、扩展屏幕”中的一种 Win+P 拓扑。显示拓扑不会在停止投图时自动恢复。
- 投出的是图卡原始像素，不包含预览中心十字、鼠标坐标、缩放或平移效果。
- 实时投图使用“只保留最新待投帧”的串行队列，快速修改参数时不会让较旧图卡在新图卡之后覆盖桌面。
- 实时开关每次启动程序均默认为关闭，避免程序启动时自动修改桌面；显示模式选择和“恢复原壁纸”选项会保存上次输入。

这是 Windows 全局壁纸方式，不是独立无边框投影窗口。扩展桌面时，图片在各屏幕上的铺放、填充或裁剪仍由当前 Windows 壁纸设置决定。

## 保存上次输入

工作台和所有功能页会保存上次输入，并在下次启动时恢复，包括：

- 当前工作台页面、各图卡类型的独立参数、画布、四边距、实时区域、圆点、行列、线宽和白框；
- 串扰的周期像素数、RGB 排列、倾斜角、当前相位和导出选项；
- 3D 显示器图卡左右区域，以及连续融合、离散光源和图片转 LightTools 的参数；
- 视频图片列表、顺序、每张静止时长、输出尺寸、帧率、格式和输出文件；
- 文本框、下拉选项、图片路径、输出格式、质量、文件前缀、最近打开和导出的文件夹；
- 预览中心十字和像素坐标的显示开关。
- 投图显示模式和停止时是否恢复原壁纸；实时投图为保护桌面状态而始终在启动时关闭。

设置文件位于：

```text
%LocalAppData%\EolTestPatternGenerator\settings.json
```

配置采用版本化 JSON 和同目录临时文件原子替换。旧版坐标/尺寸及串扰预设会迁移为当前模型。文件缺失时程序使用默认值；文件损坏或来自更高版本时，程序会提示原因，并在首次保存前先在同目录创建带时间戳和 GUID 的 `.recovery-*.bak` 原文恢复备份；备份失败时会拒绝覆盖原文件。预览缩放和平移属于临时视图状态，不保存。

## 打开、设计与构建

使用 Visual Studio 打开解决方案，而不是仅打开文件夹或单个 `.cs`：

```text
EolTestPatternGenerator.sln
```

项目文件已显式声明所有 Form/UserControl 的 `SubType` 和 `.Designer.cs` 的 `DependentUpon`，并将运行时 OpenCV 初始化移到带设计时保护的 `OnLoad`，避免 WinForms Designer 加载原生库。

若 Visual Studio 仍显示旧的 `hierarchy` 缓存错误，请关闭 Visual Studio，清理项目的 `.vs`、`bin`、`obj` 后重新打开解决方案，并从主 `.cs` 文件选择“查看设计器”，不要直接打开 `.Designer.cs`。

命令行构建：

```powershell
dotnet restore .\EolTestPatternGenerator.sln --configfile .\NuGet.Config
dotnet build .\EolTestPatternGenerator.sln -c Release --property:Platform=x64
```

输出程序位于：

```text
src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.exe
```

## 验证

先完成 Release 构建，再运行：

```powershell
# 图卡算法、几何、设置迁移、投图队列和视频帧调度自检
dotnet .\src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.dll --self-test

# MP4、FFV1、HuffYUV 的实际编码、回读、无损像素及取消安全性自检
dotnet .\src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.dll --video-self-test

# 工作台、各功能窗体、自定义控件、Designer 事件及 OpenCV 初始化冒烟测试
dotnet .\src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.dll --ui-smoke-test

# 与用户提供的参考图逐像素回归
dotnet .\src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.dll --verify "C:\Users\admin\Desktop\90K图片\EOL图卡png"

# 检查补丁空白错误
git diff --check
```

`--self-test` 覆盖纯色图、四边距及负边距、点阵双定义、3D 显示器三张图、六种固定串扰预设及旧配置兼容、导入图白框、预览坐标换算、非整数覆盖率、离散光源 4×2 参考样例、LightTools 文本、实时投图最新帧队列、目录恢复、配置持久化和旧设置迁移。投图自检使用内存假服务，不会修改真实 Windows 壁纸或显示模式。`--video-self-test` 会实际创建临时视频并解码验证三种编码器。

也可以从命令行导出 14 张历史默认图卡：`0`、`1–8`、九点、畸变、上下校正、白色矩形和全黑。

```powershell
dotnet .\src\EolTestPatternGenerator\bin\x64\Release\net8.0-windows\win-x64\EolTestPatternGenerator.dll --export-defaults ".\GeneratedCards" png 1920 1080 95
```
